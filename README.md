# Mental Workload Prediction using EEG Data
A study on EEG classification to monitor mental states by identifying workload in binary classes. It examines the effectiveness of logistic regression and convolutional neural networks (CNNs) in EEG signal classification.

Initial logistic regression with raw EEG data achieved an accuracy of about 45%. After feature extraction, which involved segmenting EEG data and calculating power spectra across different frequency bands, accuracy improved significantly to around 87%, matching the CNN's performance.

The CNN architecture also achieved an 87% accuracy rate, indicating its effectiveness in classifying EEG signals into binary categories. Both models suggest that deep learning, particularly with refined feature extraction, can significantly enhance EEG classification tasks.

The study also notes the potential for further improvement in classification accuracy through hyperparameter tuning and model architecture adjustments.
